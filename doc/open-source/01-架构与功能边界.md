# 01 架构与功能边界

浏览器管理后台 → PHP 应用 → MySQL 内容库。Python 根目录脚本负责开发服务管理、模型调用与静态导出，PHP 脚本提供数据库操作和页面渲染。

人工界面负责编辑、确认、发布、打包；AI 脚本负责生成目录与草稿。私有模型配置和运行记录位于 `.local`。生产网站由静态 HTML/CSS/JS、搜索数据、robots 和 sitemap 组成，上传后无需运行后台。

`new-project/app/src/bootstrap.php` 是数据库、页面与导航公共入口；`admin.php` 分派后台功能；`scripts/php/install.php` 创建表并执行迁移；`scripts/publishing/build.py` 是静态打包入口。模板位于 `new-project/themes/site-ID`，发布前可独立编辑。

当前后台为单维护者模式，不具备多租户隔离。宣传页和历史内容批处理仍有固定站点约定。新用户先使用通用文章、目录、模型和打包功能，再按需改造城市实例。
