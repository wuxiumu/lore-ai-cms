# 04 文章翻页与联系赞助

全站文章按发布时间倒序、ID 倒序保持稳定阅读顺序。上一篇指向列表前一篇（较新），下一篇指向后一篇（较早）。仅关联同站已发布文章，首末篇显示边界提示。动态浏览和静态导出采用同样规则。

所有站点前台页底统一显示关于本站入口、邮箱、微信和两种赞助码，后台不显示。二维码使用维护者提供的 OSS 地址，需网络加载；点击在当前页面居中弹窗放大，支持关闭按钮、遮罩点击与 Esc，关闭后焦点回到原按钮。

联系信息和图片地址目前集中在 `new-project/app/src/reader.php`，部署自己的实例时请替换为自己的信息。样式在 `new-project/app/public/reader.css`，静态打包自动复制该文件。公共页底在渲染器中追加，不需要逐站修改模板。

更新后重新打包，上传整个 ZIP 内容，包含 reader.css 与 reader.js。此前已上传的线上页面不会自动改变。
