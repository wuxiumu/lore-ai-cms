# 05 复制分享与转图提示词

所有默认文章模板统一提供复制内容、分享、复制链接、转图按钮。复制正文保留正文内的虚构标注与文章来源链接；分享优先使用浏览器原生分享，不支持时复制标题与链接。

“转图”复制文章标题、正文和简约漫画素描提示词，并不调用绘图服务。默认5张，后台每站“设置 / TDK”的“转图数量”可设置1—20的整数。提示词要求按情节拆分、黑白铅笔素描、统一人物、默认竖版3:4、无字幕水印。粘贴到你选择的绘图模型执行；实际生成数量取决于模型能力。

浏览器剪贴板不可用时提供手动复制文本框。主题旧复制工具由公共渲染器替换，避免重复按钮；公共工具只出现于文章页，后台不显示。

配置字段是 mvp_sites.image_count，首次启动安装迁移自动添加。已有安装可运行 `php scripts/php/site-settings-migrate.php`。数量变化立即影响动态页，静态网站需重新打包并上传 reader.js、reader.css 及 HTML。

## 三格连续漫画与后台提示词配置

默认每张大图上中下拼接3格连续情节，5张大图共15格。每格包含场景、动作、构图与准确中文旁白，人物和重要物件保持连续性。提示词要求图片内保留中文文字栏；模型文字表现不佳时提供准确文案供后期排字。

站点“设置 / TDK”中的“转图提示词”可直接修改，按站点保存（mvp_sites.image_prompt）。支持 {{count}} 大图数量、{{panels}} 总格数变量，文章标题、正文和来源链接自动追加。留空使用最新默认提示词。修改后动态页立即使用，静态站点需重新打包上传。此按钮只复制图文生成指令，不调用模型。

## 全局继承与顺序协议

顶部“全局转图设置”入口为 `/admin/reader-settings`，全局配置保存在私有 `.local/reader-settings.json`；站点提示词留空直接继承全局，填写则追加本站要求，也可用 `{{global}}` 在指定位置嵌入全局。两级都支持数量变量。全局配置留空恢复内置默认。

程序在提示词后追加明确顺序清单：大图编号001起、每图3格、全组连续格号、从上到下阅读，以及“文章slug-001.png”格式的建议文件名。画面仅在角落显示简洁页码（如1/5），不显示格号、文件名或技术编号。格号与文件名只用于提示词规划，避免影响阅读。

文章工具已移除单张序号与单张指令。“转图”打开居中弹窗，预览完整提示词及正文，可直接编辑，主要操作是“复制提示词与正文”。修改仅保留在当前页面，关闭再打开仍保留，刷新后重新生成。出图不满意时在模型对话里继续追问即可。弹窗支持关闭按钮、Esc 和遮罩关闭。本系统只准备复制指令，没有接管绘图模型任务、文件命名或输出校验，模型实际遵循情况需要人工确认。

修改全局配置后，所有继承站点的动态页面立即使用；静态站点须逐站重新打包上传。
